CHANGELOG
=========

1.0.2  (2026-09-28)
  - Security: the Angel One SDK's own error logger printed request headers
    (API key and session token) to the screen and to logs/<date>/app.log.
    Its logger objects are now replaced with a silent one, so this cannot
    happen regardless of how the SDK reconfigures logging.
  - No candle fetch before the first candle has closed (the API rejected
    the 08:55 request with "From datetime can't be greater than current").
  - Gentler candle-fetch retries with back-off, so a throttled request no
    longer escalates into "Too many requests".

1.0.1  (2026-09-28)
  - Starting main.py now stops any older copy of the algo that is still
    running (closing a terminal window does not always end the process).
    Two copies would have placed duplicate orders.
  - Log files are now one per day (logs/orb_YYYY-MM-DD.log) and are
    never renamed, which removes the "Logging error / PermissionError"
    messages seen at midnight rollover.

1.0.0  (2026-09-25)
  First packaged release.
  - Opening range 09:15-09:45, breakout entries until the 12:10 close,
    stop = previous candle low/high honoured only on candle close,
    target = RISK_REWARD x stop distance checked on live ticks,
    square-off at 15:10, MAX_TRADES_PER_DAY limit.
  - FUTURES mode (Nifty futures with automatic monthly rollover) and
    STOCK mode (capital x leverage sizing).
  - PAPER_TRADING switch, 24/7 runner with restart-safe daily state,
    replay tool for past candles, automatic TOTP login.
  - Fix: last eligible candle (closing at 12:10) is now always processed
    before the day is declared finished.
  - Fix: WebSocket close no longer triggers a reconnect after a
    deliberate stop.
